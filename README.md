# Rainy Days

Rainy Days is a responsive multi-page e-commerce site showcasing outdoor gear with intuitive navigation, accessible design, and clean semantic HTML/CSS.

## Prerequisites

- Node.js (v20+)
- npm

## Getting Started

### Installation

```bash
npm install
```

### Running the project

```bash
npm run dev
```

## Available Scripts

- `npm run dev` - Start development server

## Technologies

- JavaScript
- HTML
- CSS
